Tracker Script Test Page

How to Test:
  1. Open the browser's Developer Tools (F12)
  2. Go to the Network tab
  3. Filter by "track" to see tracking requests
  4. On page load, you should see a POST request to /api/track with type "visit"
  5. Click on any download link below to see a POST request with type "download"
